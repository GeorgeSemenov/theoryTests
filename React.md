# Что такое React? Зачем он нужен?
Что такое React? Зачем он нужен?

Объясните, что такое React, какие задачи он решает и почему его используют для разработки интерфейсов.

> React - JS библиотека разработанная компанией Meta, для разработки интерфейсов. Основная цель - сделать разработку модульной и предсказуемой

Ключевые особенности React, которые делают его предпочтительным для разработки интерфейсов
1) Компонентный подход - интерфейс делится на изолированные кусочки кода - компоненты.
2) Virtual DOM - React создаёт виртуальную копию DOM дерева, изменения вносятся вначале в неё (это значительно экономичнее), а затем, когда изменений накопится достаточно много - все они вносятся в реальное DOM дерево.
3) JSX (JS + XML) - специальный синтаксис, который позволяет писать HTML разметку внутри JS кода объединяя отображение с логикой.
