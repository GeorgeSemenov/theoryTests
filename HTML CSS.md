# Кастомный чекбокс
Тебе надо сделать кастомный чекбокс. Нативные чекбоксы, которые отображаются браузером довольно сложно стилизовать. В сафари они выглядят одним образом, в хроме другим, в мозилле третьим. Поэтому обычно нативные браузерные чекбоксы заменяются кастомными квадратиками, отображающимися поверх реального чекбокса, который скрывается.

Требования:
- Чекбокс должен работать с нативной валидацией HTML форм
- При клике на “Checkbox text” чекбокс тоже должен активироваться
```html
<form id="testForm">
	<label class="custom-checkbox">
		<input type="checkbox" name="agree" required>
		<span class="checkmark"></span>
		<span class="checkbox-text">Checkbox text</span>
	</label>
	<br><br>
	<button type="submit">Submit</button>
	<p id="validationMessage" style="color: red; display: none;">Please accept the terms</p>
</form>
```

```css
/* Скрываем нативный чекбокс, но оставляем его в DOM для валидации */
	.custom-checkbox input[type="checkbox"] {
		position: absolute;
		opacity: 0;
		width: 0;
		height: 0;
		margin: 0;          
	}

  /* Кастомный квадратный элемент */
	.custom-checkbox .checkmark {
		display: inline-block;
		width: 20px;
		height: 20px;
		background-color: transparent;
		border: 2px solid #333;
		border-radius: 4px;
		transition: all 0.2s ease;
		position: relative;
	}
	
	/* Галочка (стилизуем псевдоэлементом) */
	.custom-checkbox .checkmark::after {
		content: "";
		position: absolute;
		display: none;
		left: 6px;
		top: 2px;
		width: 5px; /* это просто прямоугольник*/
		height: 10px;
		border: solid white;
		border-width: 0 2px 2px 0; /* у которого две границы белые а других двух - нет*/
		transform: rotate(45deg); /* и этот прямоугольник повёрнут на 45градусов*/
	}
	
	/* Когда чекбокс в состоянии checked — меняем фон и показываем галочку */
	.custom-checkbox input[type="checkbox"]:checked + .checkmark {
		background-color: #2196F3;
		border-color: #2196F3;
	}
	
	.custom-checkbox input[type="checkbox"]:checked + .checkmark::after {
		display: block;
	}
	
	/* Фокус (для доступности) */
	.custom-checkbox input[type="checkbox"]:focus + .checkmark {
		box-shadow: 0 0 0 2px rgba(33, 150, 243, 0.5);
	}
	
	/* Hover эффект */
	.custom-checkbox:hover .checkmark {
		border-color: #2196F3;
	}
```

# Базовый поток документа
Что такое базовый поток документа? Как выбить элемент из базового потока?
> Базовый поток документа - последовательность расположения элементов согласно их расположению в HTML коде и их типу (блочный или строчный)
> - Блочные - переносятся на новую строку и занимают всё пространство по ширине родителя
> - Строчные - занимают пространство согласно своему содержимому, выстраиваются в строку.
> - строчно-блочные (inline-block) - ведут себя как строчные элементы, но могут иметь отступы и установленные размеры width и height
	Чтобы выбить элемент из потока нужно:
	1) изменить его position на любое значение кроме static или relative (absolute, fixed, stiky)
	2) Установить float: right/left (контент будет обтекать слева или справа)

# Единицы измерения
Распиши, чем отличаются следующие типы значений в CSS: em, rem, vh, vw, px
	em  - размер шрифта родительского элемента. (если у родителя font-size = 16px, то у дочернего элемента 1em будет соответствовать 16px)
	rem - тоже самое что em только за основу берётся font-size корневого элемента (html)
	vh - viewport height - 1vh - 1% от высоты всего вьюпорта (окна просмотра)
	vw - viewport width - 1vw - 1% от ширины всего вьюпорта
	px - логический пиксель - Единица измерения к которой привязаны все остальные величины длины. 1 логический пиксель примерно равен одному физическому пикселю монитора при стандартной плотности экрана, но если плотность выше, то один px может соответствовать нескольким реальным пикселям (чтобы сохранить пропорции)
	
Какие ещё есть типы значений в CSS? Возможно, какие-то были добавлены совсем недавно?
	lvh/svh/dvh : 
		- lvh (large viewport height) - 1% размера вьюпорта когда адресная строка скрыта вверху (на мобильных устройствах).  Это максимально возможная высота. lvh = vh 
		- svh (small viewport height) - 1% размера вьюпорта когда адресная строка выдвинута. Минимально возможная высота.
		- dvh (dynamic viewport) - 1%  размера вьюпорта, когда адресная строка выдвинут и когда она скрыта, поэтому dvh - непостоянен (динамичен)
	vi/vb:
		- vi (viewport inline) - 1% размера вьюпорта в строковом направлении (inline axis), например для языков которые пишут слева направо и с права на лево (английский и арабский)- vi эквивалентен vw. Если же речь заходит о языках, в которых текст идёт сверху вниз (японский) то vi становится эквивалентен vh.
		- vb (viewport block) - 1% размера в блочном направлении (block axis) , по аналогии с vi . для английского языка эквивалентен vw , для японского - vh 
	lh/rlh:
		- lh - высота строки элемента
		- rlh - высота строки корневого элемента

# Центрирование элементов
Перечисли максимальное количество способов (минимум 4), как можно центрировать элемент в стандартном HTML документе
* flexbox
```css
.parent{
	display: flex;
	justify-content: center;
	align-items: center
}
```
* text-align
```css
.parent{text-align: center}; /* работает с inline элементами*/
.child{display:inline-block} /* делаем элемент строчноблочным, чтобы text-align сработал */
```
- grid
```css
.parent{
	display:grid;
	place-items: center;
}
```
- position (absolute)
```css
.parent{
	position: relative; /* чтобы позиционировать потомков относительно родителя */
}
.child{
	position: absolute;
	top: 50%;
	left: 50%;
	transform: translate(-50%, -50%)
}
```
- margin 0 auto
```css
.child{
	width: fit-content; /* или можно задать точное значение ширины */
	margin:0 auto
}
```

# Схлопывание отступов
Что такое схлопывание margin? 
> схлопывание марджинов - результат высчитывания отступа между соседними блоками, которые имеют отступы по направленю друг к другу. Результирующий отступ будет равен не сумме этих оступов, а максимальному значению из этих двух.
```css
.block1 { margin-bottom: 30px; }
.block2 { margin-top: 20px; }
/* Расстояние между блоками = 30px (не 50px) */
```
Где оно может быть полезным?
	- **Заголовки и параграфы** — стандартные стили браузера используют схлопывание, чтобы расстояния между абзацами были комфортными, не создавая двойных отступов.
	- **Вертикальный ритм в типографике** — помогает поддерживать единообразие расстояний между элементами, не заботясь о накоплении отступов.
 Назови как минимум 2 способа его избежать
```css
/* способ 1 */
.parent {
    display: flex;
    flex-direction: column;
}
/* Схлопывания между дочерними блоками не происходит */

/* способ 2 */
.parent {
    border-top: 1px solid transparent;
    /* или */
    padding-top: 1px;
}
```

# Контекст наложения
Что такое контекст наложения? Как создать новый контекст наложения?
> контекст наложения - иерархическая группировка элементов в CSS, определяющая порядок их отрисовки по оси Z. Элементы внутри одного контекста наложения сортируются по `z-index`, а контексты наложения изолированы друг от друга.
	Создать контекст наложения можно следующими способами:
	- position: не static + z-index : не auto
	- display: flex / grid + z-index : не auto
	- opacity < 1
	- transform, filter, backdrop-filter, perspective
	- isolation: isolate

Напиши небольшой пример, где \<div class="item1" /> невозможно будет разместить над \<div class="item2" />
	Для этого нужно обернуть item2 в родительский элемент и задать ему отдельный контекст наложения. 
```html
<!-- Надо сделать так, чтобы item1 не мог быть над item2 тут код менять нельзя -->
<div class="item1"></div>
<div class="parentItem2">
	<div class="item2"></div>
</div>
```

```css
/* код писать только тут */
.parentItem2{
	position: absolute;
	top: 0;
	left: 0;
	z-index: 1; /*задаётся новый контекст наложения*/
}

.item2{
	z-index: 2; /* относительно нового контекста наложения по оси Z выстраиваются дочерние элементы */
}
```
